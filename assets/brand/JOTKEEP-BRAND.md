# Jotkeep 品牌方向 01

## 品牌定位

Jotkeep 是一款安静、直接、可长期拥有的本地 Markdown 工作台。

品牌不强调“管理更多信息”，而强调三件事：

- 写作动作足够轻；
- 内容留在本地；
- 文字可以被长期拥有。

## 标志含义

标志将品牌首字母 `J`、羽笔和汉字“记”的动作合并为一个连续轮廓。

品牌名由两个动作构成：

- `Jot`：快速写下；
- `Keep`：保存、持有并长期拥有。

`J` 同时承担 `Jot`、羽笔和“记”的视觉联想。羽锋向右上延展，表达思考与书写；
下方圆钝收笔形成承托，表达稳定与长期保存。

## 几何原则

- 主轴约向右倾斜 14°；
- 笔杆与底部弧线保持连续切线；
- 底部采用开放浅弧，不形成封闭回钩；
- 左下端点使用圆钝收口，不使用针尖；
- 羽锋包含三组递减切口，沿同一斜向节奏排列；
- 标志依靠轮廓和负形识别，不增加描边、阴影或装饰点。

## 色彩

| 用途 | 色值 |
| --- | --- |
| 墨色 / 主标志 | `#252622` |
| 纸色 / 主背景 | `#F7F7F4` |
| 雾灰色 / 应用图标底板 | `#D4D3CE` |
| 灰色 / 辅助信息 | `#83857D` |

主标志只使用单色。应用图标使用雾灰色圆角底板与墨色标志，不叠加其他具象元素。

## Slogan

主推荐：

> 所记，皆归于你。

它同时表达本地优先、长期拥有和个人空间，不把技术实现直接写进口号。

备选：

- 写下此刻，留在本地。
- 安静地写，长久地留。

## 字体

- 英文名称：ComicShannsMono Nerd Font，Bold；
- 中文 slogan：Hannotate SC；
- 静态品牌资产将文字转为矢量轮廓，避免跨平台字体替换；
- 正文与界面沿用应用的默认字体配置。

## 使用边界

- 独立标志建议不小于 `24px`；
- 小于 `24px` 时允许羽毛切口合并为轮廓，不额外加粗细节；
- 标志四周至少保留一倍主笔杆宽度的净空；
- 禁止改变倾角、拉伸比例或单独旋转羽锋；
- 禁止恢复绿色圆点；
- 禁止在标志本体添加渐变、立体高光、投影或拟物羽毛纹理；应用图标底板可使用系统级轻阴影。
