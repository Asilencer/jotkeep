# Jotkeep 功能实现清单

更新于 2026-07-23。清单以“用户可完成完整任务且重启后仍有效”为可用标准，不以页面存在作为完成。

状态：`可用`、`排除`。仍需发布前回归的内容单列为终验，不把已具备的能力误标成未实现。

## 1. 本地资料库与文档

| 能力 | 状态 | 完成标准 |
| --- | --- | --- |
| Markdown 新建、读取、原子保存 | 可用 | 笔记、文章和收藏可创建、编辑、重启后打开；同一文档串行保存，临时文件同步后原子替换，关闭应用前会等待最后一次输入落盘。 |
| 既有资料库扫描 | 可用 | 扫描 `notes/articles/clips` 下的 Markdown，标题与更新时间进入集合。 |
| 文档元数据目录 | 可用 | `.notedown/catalog.json` 保存项目归属和归档状态，不污染正文；同一 JSON 文件串行写入，损坏内容会先保留恢复副本。 |
| 归档与恢复 | 可用 | 活跃集合排除归档项；归档页可恢复。 |
| 删除边界 | 可用 | 只移动到 macOS 废纸篓，不提供不可恢复的直接删除。 |
| Front Matter | 可用 | 编辑时保留完整原文，标题与标签可进入索引，未知字段不被改写。 |
| 文件变更监听 | 可用 | 外部新增、修改、重命名、删除 Markdown 后自动刷新集合与索引。 |
| 全文索引 | 可用 | `⌘K` 可搜索标题、正文、标签和中文短词，并展示摘要；文件指纹未变化时复用解析结果，只重读变更文件。 |
| 冲突与版本恢复 | 可用 | 外部修改时不会静默覆盖；可载入磁盘内容或保留当前内容，并可恢复最近 50 个本地版本。 |

## 2. 编辑器与组件

| 能力 | 状态 | 完成标准 |
| --- | --- | --- |
| 树形块模型与稳定光标 | 可用 | 普通输入、组合输入链路、跨块选区、结构删除与撤销均由 Slate 模型维护；真实 macOS 中文输入法候选确认保留为发布前终验。 |
| `/` 与 `、` 命令 | 可用 | 可插入目标组件，分页和定位稳定；菜单会按表格、高亮块与分栏上下文过滤不兼容结构。 |
| 块工具与拖拽 | 可用 | 可复制、删除、同层拖动并在视口边缘自动滚动；不兼容的跨高亮容器落点会被拒绝。 |
| 行内工具栏 | 可用 | 混合格式、颜色、链接、对齐和跨块格式已验收；链接只允许单块选区。 |
| T01–T21 | 可用 | 所列文本与结构组件均可插入、编辑和保存；复杂边界仍按运行时矩阵做发布回归。 |
| M01–M03 | 可用 | 图片、视频/文件、网页卡片可插入；附件复制、匿名外部引用、失效重选与未引用清理已闭环并完成运行时验收。 |
| C01/C10/C17 | 可用 | 任务、提醒、链接按钮的编辑、退出、删除与撤销已验收；不实现成员、通知或权限。 |
| Markdown 往返 | 可用 | 标准块与扩展指令可保存；软换行、未知内联语法及未知 `:::` 扩展在未编辑时原样写回。 |

编辑器的详细行为基线见 [editor-runtime-parity.md](./editor-runtime-parity.md)。

## 3. Today 与任务

| 能力 | 状态 | 完成标准 |
| --- | --- | --- |
| Daily 文档切换与保存 | 可用 | 月历选择日期后读写对应 Daily Markdown。 |
| 天气与农历 | 可用 | Open-Meteo、缓存、归属、WebGL 天气场景和农历均可用。 |

## 4. 项目与收藏

| 能力 | 状态 | 完成标准 |
| --- | --- | --- |
| 项目浏览与重命名 | 可用 | 浏览、筛选、重命名与重启持久化可用。 |
| 项目 CRUD | 可用 | 新建、重命名、归档、恢复和删除均持久化；归档同步归档项目文档，删除会在确认后把项目文档移到废纸篓，并解除任务的项目归属。 |
| 文档归属编辑 | 可用 | 文档属性行可切换或移除项目，结果写入 catalog。 |
| 收藏列表与编辑 | 可用 | 真实收藏 Markdown 进入统一集合，可继续批注和编辑。 |
| URL 收藏 | 可用 | 支持任意 HTTP/HTTPS 与重定向；抓取元数据和正文，失败时退化为书签。 |
| 附件管理 | 可用 | 支持复制或匿名外部引用、内容哈希去重、相对路径、打开、失效重选、未引用清理和目录迁移。 |
| 系统分享入口 | 可用 | Share Extension 可接收单个网页、纯文字、图片、视频或文件，并安全导入资料库。 |

## 5. 发布、账号与个人主页

| 能力 | 状态 | 完成标准 |
| --- | --- | --- |
| 发布草稿列表 | 可用 | 只展示用户从笔记或文章中主动发起并持久化的草稿。 |
| 发起发布与来源版本 | 可用 | 文档显式发起并固定 revision；来源变化后由用户决定是否同步。 |

| 个人资料编辑 | 可用 | 用户名、头像和网站链接随当前资料库持久化，侧边栏与个人页共用数据。 |
| 热力图与活动 | 可用 | 文档、Daily、收藏、任务完成和发布事件生成本地热力图与最近活动。 |

| 能力 | 状态 | 完成标准 |
| --- | --- | --- |

## 明确排除

- 收件箱、反向链接、关系图谱。
- 多人协作、评论、权限、协作任务成员和通知。
- X OAuth、平台排版模板配置和插件系统。
- 复制第三方私有源码、服务端协议或品牌资产。
- Developer ID 公众分发、公证和自动更新服务。

## 实施顺序

1. 完成编辑器与组件运行时矩阵的原生输入法和复杂边界终验。
2. 完成源码预览及 ad-hoc 安装包的关闭保存、异常恢复和深链终验。
3. 发布保持 X Web Intent 人工交接；除非未来明确改用 X API，否则不新增自动回执、OAuth 或重试队列。
