# 块编辑器运行时对照矩阵

目标是验证用户可观察的编辑行为、状态转换和组件交互，不依赖第三方私有源码、服务端能力或品牌资产。

## 已核验的当前运行时基线

- 页面、块和文本区分别拥有稳定的 `data-block-id`、`data-record-id` 与 zone 容器。
- 文本行由 `ace-line`、`data-leaf` 和结尾占位节点组成；`data-slate-editor` 是兼容标记，不代表 Slate DOM。
- 行内提醒以不可编辑的 inline component 嵌入文本叶节点，并由选区模型维护两侧光标位置。
- 复杂块通过独立 block renderer 和懒加载模块渲染；其 42×26px 块工具锚定在
  容器顶部，而不是随整个高块垂直居中。普通文本与标题的工具仍按文字行居中。
- 结构操作通过模型事务更新，并在必要时显式同步浏览器 Selection；不是在每次输入后重写文本 DOM。
- 高亮块监听本地事务；当子节点被清空时会自动补入一个空正文块。高亮块内的 Markdown
  快捷解析会禁用代码块与分割线转换，避免破坏容器边界。
- 文字颜色使用 `textHighlight`；默认文字使用主题语义 token，浅色主题呈深色，
  深色主题呈浅色，不序列化为固定黑色。背景色使用
  `textHighlightBackground` 的 15 个语义 token。
- 行内背景渲染为 `2px 0` 的纵向 padding、无圆角；行内代码中的背景 padding 为 `1px 0`。

## 完成定义

每项必须同时满足：

1. 运行时行为与既定交互基线一致。
2. 中文输入法、鼠标、键盘和触控板路径都通过。
3. 保存重载后节点语义不变。
4. 撤销重做不会破坏 Selection 或相邻块。
5. 浮层不被裁剪，焦点关闭后回到原位置。
6. 不依赖第三方私有服务、内部包或未公开协议。
