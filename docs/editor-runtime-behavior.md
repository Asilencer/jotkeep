# 编辑器运行时验收矩阵

更新于 2026-07-23。状态以源码预览中的真实输入结果和当前代码为准，
不以组件是否出现在 `/` 菜单中判断。

## 已验证

| 行为 | 当前结果 |
| --- | --- |
| 连续输入与删除 | 行尾连续输入、退格和行内移动后编辑均保持 Selection，不跳到行首。 |
| 中文输入法 | Chromium composition 候选确认期间的 Enter 不拆块；候选上屏后单次撤销可完整恢复。 |
| 中文组件入口 | `/` 与 `、` 均可唤起组件菜单。 |
| 菜单键盘导航 | 上下键、Page Up/Page Down、Enter 和 Escape 可用；选中项保持在可视区。 |
| 菜单上下文 | 根文档展示全部组件；表格单元格只保留可安全回存的文本、链接与提醒；高亮块和分栏内不再递归插入自身结构。 |
| 普通 Enter | 段落、列表和引用由 Slate 模型拆块，不再把浏览器换行符写进同一块。 |
| 标题 Enter | 标题末尾进入现有空正文块；标题中间拆分后右侧转换为正文。 |
| 列表退出 | 有内容的列表 Enter 新建同类列表，空列表 Enter 转为正文。 |
| 块首退格 | 标题、列表、任务、引用和代码在块首退格时先转换为正文，不吞掉文字。 |
| Markdown 快捷输入 | 标题、列表、任务、引用和分割线均在 Slate `insertText` 模型层原子转换，不依赖键盘布局。 |
| 分割线删除 | `---` 加空格生成分割线；在后续空正文退格会删除分割线并保留输入位置。 |
| 行内代码 | 中英文反引号均在 Slate `insertText` 模型层转换为行内代码，字号固定继承正文。 |
| 下划线 | 选区工具栏与 `⌘U` 均可设置可见下划线，并写回 Markdown 扩展语法。 |
| URL 识别 | 无协议链接只接受明确域名、localhost 或 IPv4；中文句号不再被误判为域名。 |
| 组件插入与撤销 | 键盘选择组件后可插入，`⌘Z` 可撤销结构变化。 |
| 块拖动 | 顶层块和高亮块子节点可同层排序；拖到长文档视口上下边缘会连续滚动，撤销可恢复原顺序。 |
| 代码块键盘 | Tab 插入两个空格，`⌘Enter` 退出到相邻正文。 |
| 表格 | Tab/Shift Tab 在单元格间移动；末格 Tab 新建一行。TSV 多行多列粘贴会扩展表格并落入对应单元格，一次撤销可整体恢复。 |
| 富文本粘贴 | 网页 HTML 会转换为标题、行内格式、链接、列表和表格后进入块模型；脚本、嵌入对象与危险 URL 不会进入文档。纯文本模式仍只写入文字。 |
| 分栏 | 可增至 2–4 栏并拖动调整比例；跨栏选区可应用行内格式；减少非空栏会把内容并入前一栏，空栏直接移除，且一次撤销可恢复。宽度和各栏正文会写回 Markdown。 |
| 高亮块 | 支持嵌套正文、图标与色调面板、整块及子块复制/删除/撤销；子块可在同一高亮块内拖动排序，首个子块块首退格会解除高亮容器并保留正文。 |
| 对象组件 | 任务、日期提醒和链接按钮可直接输入；时间与正文同为 16px，长按钮保持单行截断，数据可写回 Markdown。 |
| 媒体与附件 | 图片、视频或文件均可替换；复制模式按内容哈希去重，失效外部引用显示重新选择入口，超过 256MB 的文件在读取前拒绝且不写入 Markdown。清除资源后可重新选择，未引用附件能被清理检查识别。 |
| 未知扩展语法 | 未识别的 `:::` 指令不会被解析成普通段落；以安全原始节点展示和编辑，保存时保留完整源码。 |
| 跨块格式 | 跨段选区可统一应用粗体，选区同步完成后两端块保持一致。 |
| 混合行内格式 | 粗体、斜体、下划线、删除线、行内代码、文字色和背景色可叠加；链接和对齐正确写回 Markdown。跨块选区禁用链接，避免生成重复行内节点。 |
| 光标与空白画布 | 文档尾部保留可继续输入的正文位置，点击画布空白可回到末尾。 |

## 范围边界

- 对齐既定的块模型、Selection、键盘、浮层、拖拽和组件交互。
- 不依赖第三方私有源码，不接入评论、成员、权限、协作通知等业务能力。
- Markdown 文件仍是内容真源，非标准组件使用可读扩展语法保存。
