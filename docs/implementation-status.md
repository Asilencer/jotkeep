# Jotkeep 实现状态

更新于 2026-07-23。状态以当前仓库可运行代码为准，不以页面上是否出现入口作为“已实现”的判断依据。

## 已可用

| 范围 | 当前能力 |
| --- | --- |
| macOS 桌面壳 | Electron 窗口、原生交通灯联动、侧边栏收起、设置路由、沙箱与 Context Isolation。 |
| 信息架构 | Today、笔记、文章、收藏、任务、项目、发布、个人主页和设置页面。集合页统一支持时间线；资料库支持按项目组织，项目支持按内容类型筛选。 |
| Markdown 文档 | 笔记、文章和收藏可新建或从资料库扫描，编辑后按文档串行写入；临时文件落盘后执行同步与原子替换。Front Matter、软换行、未知内联语法与未知 `:::` 扩展会保留，只有真正修改过的块才规范化输出。可通过系统文件选择器批量导入 Markdown，同名目标不会被覆盖。保存时使用内容 revision 检测外部修改；索引刷新不会覆盖未保存输入，冲突可选择载入磁盘或保留当前内容。 |
| 编辑器内核 | Slate 块编辑、Markdown 源码模式、自动保存、撤销重做、拖拽和块操作。 |
| 编辑器输入 | `/` 和 `、` 菜单、行内链接及模型级 Enter；富文本粘贴会保留支持的标题、格式、链接、列表和表格，同时剔除脚本与危险 URL；编辑设置会实时生效。 |
| 编辑器媒体 | 支持粘贴与拖放；媒体复制到资料库附件目录并写入相对路径。 |
| 文档组件 | T01–T21 指定文本组件、M01–M03 媒体组件、C01 任务、C10 日期提醒、C17 链接按钮。表格、分栏、代码语言和书签元数据均有对应交互。 |
| 导航与查找 | `⌘K` 可搜索页面、项目及文档标题/正文/标签，支持中文短词和摘要；`⌘N` 可快速新建。 |
| 长内容导航 | 正文左侧 Minimap 常驻，支持 Scroll Spy、拖动定位和悬浮标题；页面不显示传统滚动条。 |
| 外观设置 | 主题、前景色、背景色、强调色、UI 字体、代码字体、字号、对比度、侧边栏透明度和动态效果可持久化并作用于界面。 |
| 国际化 | 支持跟随系统、简体中文和英文；核心界面即时更新。 |
| 本地目录 | 默认资料库为 `~/.jotkeep`，与源码仓库物理隔离；历史上与源码重合的资料库会在写入屏障内复制、逐文件校验后切换，旧副本不删除。可选择其他资料库目录；路径变化会重建 watcher 与索引并切换工作区。 |
| 资料库索引与归档 | 扫描与监听笔记、文章、收藏 Markdown；项目/归档元数据写入 catalog，可恢复或移到 macOS 废纸篓。 |
| 任务与项目 | 任务可新建、编辑、完成、删除并持久化；在项目页新建文档或任务会自动归属当前项目。项目可新建、改名、归档、恢复和删除；归档与恢复会同步作用于项目内文档，删除按确认结果处理项目文档。 |
| 个人活动 | 文档、Daily、收藏和任务完成事件会写入本地活动记录；个人页热力图和最近活动由真实数据生成，旧文档以文件修改时间补入。 |
| 个人资料 | 用户名、头像和网站链接写入当前资料库；个人页与侧边栏共用同一份资料，网站使用系统浏览器安全打开。 |
| 发布草稿 | Today、笔记、文章整篇及选中段落可主动固定当前 Markdown 版本；发布页只展示主动发起内容，当前仅支持 X，具备来源更新检测、纯文本预览、复制、X Web Intent、本地队列、手动发布确认和安全移除。 |
| URL 收藏 | 支持任意 HTTP/HTTPS 和重定向；保存元数据与正文，失败退化为书签。 |
| 系统分享 | macOS Share Extension 接收单个网页、纯文字、图片、视频或文件；二进制内容经沙箱暂存区和随机令牌导入资料库，无需付费 Team 或 App Group。 |
| 附件管理 | 支持复制或外部引用：复制附件按内容哈希去重并保存相对路径；外部引用以匿名标识写入 Markdown，真实路径仅保存在当前资料库。失效附件可重新选择，也可清理未引用附件或安全迁移附件目录。 |
| 备份与导出 | 可手动或按日/周自动备份用户数据，按保留数量清理旧备份；应用内可校验、预览并恢复备份，恢复前会创建安全快照；支持完整资料库和配置导出。 |
| 历史版本 | 文档编辑时按内容变化保存本地快照，单篇保留最近 50 个版本；可从页眉查看并恢复，恢复前的当前内容也会先保留。 |
| 系统检索 | 活跃文档的标题、正文和标签进入设备端 Core Spotlight；系统结果通过 `notedown://` 深链回到对应文档，归档内容不进入索引。 |
| 本地数据保护 | 文档、目录元数据、任务、项目、发布草稿和个人资料进入统一写入协调器；应用关闭前等待全部持久化操作。备份/恢复持有维护屏障，恢复完成后拒绝此前排队的旧写入。无法解析的本地 JSON 会先保留带内容指纹的恢复副本，再启用空白存储并提示用户。 |
| 本地应用包 | 可生成 Apple Silicon `Jotkeep.app`，包含天气、Spotlight、Share Extension、URL Scheme 和 ad-hoc 签名；打包排除个人资料库。 |

## 已闭环的产品边界

| 范围 | 当前边界 |
| --- | --- |
| Today | 月历、翻月、Daily 日期切换和当天文件定位已接通；Core Location、Open-Meteo 实时天气、20 分钟缓存、数据归属和 WebGL2 天气场景已经落地。任务仍由任务菜单管理，不在 Today 重复展示。 |
| 任务 | CRUD 与跨重启持久化已接入；包含具体时间的待办任务会调度 macOS 本地通知，完成、取消或关闭提醒后会撤销调度。 |
| 发布 | 草稿、X 预览、复制、Web Intent 和手动发布确认已接通。Web Intent 会把内容交给 X 网页，应用不使用 OAuth/API，因此无法自动读取平台发布结果，也不存在可由应用自动重试的 API 请求。 |
| 设置 | 语言、编辑、附件、备份、导出和索引均可用；组件内置。 |

## 仍需发布前终验

- 使用真实 macOS 中文输入法完成候选确认、跨块选区、撤销和组合输入回归。
- 按编辑器运行时矩阵逐项复核空高亮块退出、复杂表格和跨容器拖拽等边界交互。
- 在个人 Mac 的源码预览与 ad-hoc 安装包各完成一次关闭前保存、异常恢复副本和深链回归。

这些是发布验收证据，不是新的产品功能入口；验收失败时再按对应运行时修复。

## 2026-07-23 工程完整性审计

| 主题 | 识别的问题 | 当前处理 |
| --- | --- | --- |
| 数据一致性 | 不同 JSON 与 Markdown 写入链路各自排队；备份/恢复可能与待写入操作交错。 | 写入统一进入协调器；备份/恢复建立维护屏障；关闭窗口等待全部操作；恢复后的陈旧写入会被拒绝。 |
| 数据加载 | 项目、任务、个人资料和发布草稿使用单个 `Promise.all`，一个域失败会阻止其他域进入可用状态。 | 改为独立就绪状态和 `Promise.allSettled`；单域损坏只影响对应功能并给出提示。 |
| Markdown 保真 | 解析器会把软换行和暂不支持的语法重新排版，未编辑内容也可能发生变化。 | 块保留原始源片段与语义快照；未修改块原样写回，修改块才按当前 Markdown 规范输出，并有回归测试。 |
| 搜索性能 | watcher 每次失效都会重新读取全部 Markdown。 | 索引按 inode、大小、mtime 和 ctime 复用解析结果，只重读真实变化的文件；手动重建和备份恢复会清空缓存。 |
| 运行时边界 | IPC 只依赖 TypeScript 声明；设置值未经统一运行时校验；Renderer 崩溃没有恢复入口。 | IPC 校验 sender 与载荷形态；设置统一清洗和边界收敛；增加 Renderer Error Boundary；原生菜单与保存提示跟随界面语言。 |
| 稳定标识 | 段落发布使用每次解析生成的随机节点 ID，重载后无法稳定去重。 | 发布标识改为文档与 Slate 路径组合，并用固定内容快照兼容移动前后的已有草稿。 |
| 工程职责 | 主进程集中承担存储队列、索引缓存与 IPC 合约，难以独立验证。 | 写入协调器、文件指纹缓存和 IPC 合约拆为小模块；新增 `npm run check` 覆盖类型、回归和主进程语法。页面仍在快速迭代，不为追求文件大小做无关拆分。 |
| 资料隔离 | 默认资料库与源码目录在大小写不敏感文件系统上指向同一 inode。 | 默认路径改为 `~/.jotkeep`；启动时只迁移资料数据，不复制源码资产，逐文件校验后切换并保留旧副本；源码忽略资料目录。 |

## 明确不在范围内

- 收件箱、反向链接、多人协作、协作任务成员和通知。
- X OAuth、平台排版模板配置和插件系统。
- Developer ID 公众分发、公证和自动更新；当前只面向个人 Mac 本地安装。
